# 2DGP 1차 발표 PPT 보완 정리

## 전체 의견

현재 발표 자료에는 게임 콘셉트, 조작, 진행 구조, 강화 요소, UI 구상, 개발 일정이 포함되어 있어 게임의 큰 방향은 파악할 수 있다. 다만 실제 플레이 규칙과 제작 범위를 판단하기에는 수치, 예시, 승패 조건이 부족하다. 특히 **추격 중 성장하는 재미가 최종 보스전으로 어떻게 이어지는지**를 명확하게 설명할 필요가 있다.

## 우선 구체화할 핵심 항목

### 1. 한 판의 플레이 흐름

시작부터 종료까지의 흐름을 도식으로 보여준다.

> 게임 시작 → 보스에게 쫓기며 스테이지 진행 → 몬스터 처치 및 경험치·보물상자 획득 → 강화 선택 → 최종 보스전 → 승리 또는 패배

함께 정할 사항:

- 스테이지별 제한 시간과 전체 예상 플레이 시간
- 스테이지가 넘어가는 조건(시간4분경과)
- 사망 또는 실패 시 처리 방식과 재도전 방식(게임오버 창 생성(재시도, 타이틀이동))
- 강화 선택이 플레이 흐름에서 발생하는 시점(레벨증가, 상자획득)

### 2. 러닝액션의 실제 진행 규칙

현재 조작 설명은 좌우 이동 중심이므로, 러닝액션 장르와 조작이 어떻게 연결되는지 정리한다.

- 캐릭터가 자동으로 달리는지, 플레이어가 직접 이동하는지
- 화면이 자동으로 스크롤되는지
- 보스와 플레이어 사이의 거리가 어떤 상황에서 변하는지
- 보스에게 따라잡히거나 추격 구간의 위험에 실패하면 어떤 결과가 생기는지
- 발판을 이용한 이동과 일반 점프·하강의 차이

### 3. 생존 및 전투 규칙

- 일반 몬스터와 보스에게 접촉하거나 공격받았을 때의 피해
- 체력, 무적 시간, 피격 경직의 적용 방식
- 회복 아이템의 획득 방법, 회복량, 보유 한도
- 플레이어의 기본 공격 방식과 공격 범위
- 보스 공격을 피하는 방법과 보스에게 피해를 주는 방법

### 4. 강화 선택과 스킬 예시

강화 카드의 실제 예시를 5~10개 정도 제시하면 성장 방식이 이해하기 쉬워진다.

예시:

- 공격력 증가
- 공격 범위 증가
- 최대 체력 증가
- 점프 또는 하강 공격 강화
- 패시브 공격 추가
- 회복 아이템 획득

추가로 명시할 사항:

- 레벨업 시 강화 2회가 선택 화면을 두 번 띄운다는 의미인지
- 카드 3개 중 선택지가 어떤 기준으로 등장하는지
- 같은 강화의 중복 선택 가능 여부와 중첩 한도
- 액티브 스킬별 효과, 쿨다운, 조준·발동 방식
- 패시브 스킬의 발동 조건과 보스전에서 감소하는 피해량

### 5. 최종 보스전의 승리 조건과 예외 규칙

현재 자료에는 5개 스테이지 뒤 보스전으로 전환된다는 설명과, 보스전 전에 보스를 처치할 수 있다는 설명이 함께 있다. 서로 모순되지 않도록 아래 흐름을 확정한다.

- 보스전 진입 전 보스를 처치하면 보스전이 생략되는지
- 보스전에서 보스 체력을 모두 깎으면 승리하는지
- 보스와 접촉하면 즉사한다는 규칙이 보스전에서도 동일한지
- 보스전에서 패배했을 때 처음부터 재시작하는지

## 슬라이드별 보완 제안

### 2장: 게임 소개

- 플레이어가 달성해야 하는 목표
- 핵심 재미를 설명하는 한 문장
- 참고 게임의 어떤 요소를 참고했으며 어떤 점을 차별화했는지

### 3장: 조작

- 기본 공격 조작
- 점프·하강 공격의 발동 조건과 판정
- 액티브 스킬의 사용 후 쿨다운 표시 방식
- 마우스 조준의 기준과 조준 불가 상황

### 4장: 게임 구조

- 스테이지별 테마, 장애물, 몬스터 예시
- 스테이지별 시간 또는 진행 조건
- 몬스터 처치 시 획득하는 경험치 기준
- 보스의 대표 공격 패턴 2~3개와 회피 방법

### 5장: 강화

- 실제 강화 카드 예시와 효과 수치
- 선택지 구성 및 중복 강화 규칙
- 각 패시브·액티브 스킬의 효과와 사용 조건

### 6장: UI

현재 UI 그림에 각 요소의 역할과 변화 조건을 표시한다. 체력·경험치 외에 다음 정보를 고려한다.

- 보스와의 거리 또는 추격 상태
- 액티브 스킬의 쿨다운
- 남은 회복 아이템 수
- 현재 스테이지와 진행 시간

### 7장: 개발 계획

각 주차의 산출물과 완료 기준을 테스트 가능한 형태로 작성한다.

예시:

- 2주차: 좌우 이동, 점프, 하강 공격, 착지 판정 구현 및 테스트
- 3주차: 추격 구간의 장애물·몬스터 패턴 구현, 한 스테이지 완주 테스트
- 4주차: 보스 공격 패턴과 승리·패배 흐름 구현, 전체 플레이 테스트

## 발표 자료에 우선 추가할 내용

분량이 제한된다면 다음 세 가지를 우선 추가한다.

1. **플레이 흐름도:** 게임 시작부터 보스전과 종료까지의 흐름
2. **스테이지 규칙표:** 스테이지별 진행 조건, 위험 요소, 보상
3. **강화 카드 및 보스 패턴 예시:** 실제 플레이의 선택과 전투 방식을 보여주는 자료

## 최우선 결정 사항

기획을 더 구체화하기 전에 다음 질문에 먼저 답을 정리한다.

1. 플레이어 이동과 화면 스크롤은 자동인가, 수동인가?
2. 추격 중 보스와의 거리는 어떤 규칙으로 바뀌는가?
3. 보스전 전 처치와 최종 보스전 진입은 어떻게 양립하는가?
4. 강화 선택은 언제, 몇 번 발생하며 어떤 효과를 제공하는가?
5. 플레이어가 이기거나 실패하는 정확한 조건은 무엇인가?
